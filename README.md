# 🚀 HR Automation Projects

Welcome to the **HR Automation Projects** repository.

This repository contains a collection of Google Apps Script-based automation projects developed to streamline various Human Resources (HR) processes. Each project focuses on eliminating repetitive manual tasks, improving accuracy, and increasing operational efficiency through automation.

---

## 📌 Repository Overview

The repository currently includes the following automation projects:

| 📂 Project | 📖 Description |
|------------|----------------|
| 🎂 Birthday Wishes Automation | Automatically identifies employees whose birthday falls on the current day and sends personalized birthday wishes through Google Chat. |
| 🎉 Work Anniversary Automation | Detects employee work anniversaries and automatically sends anniversary wishes in Google Chat, ensuring timely recognition of employees. |
| 📄 Intern Experience Letter Automation | Automates the generation of internship experience letters using predefined Google Docs templates by replacing placeholders with intern details and generating final documents. |
| 💼 Full-Time Employee Experience Letter Automation | Automates the creation of experience letters for full-time employees by retrieving employee information, generating personalized documents, and handling the document generation workflow. |
